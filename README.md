# Nachtfalter – Personal Command Center

Einfache, selbstgehostete Chat-UI für den Wechsel zwischen Gratis-Modus (z. B. Llama-3 / Groq) und Experten-Modus (Grok).

## Live-Vorschau

Sobald GitHub Pages aktiviert ist:

**https://mariechrisart77-web.github.io/nachtfalter/**

Sofortige Vorschau ohne Pages:

https://htmlpreview.github.io/?https://github.com/mariechrisart77-web/nachtfalter/blob/main/index.html

## Features

- Dunkles Design mit lila Akzenten
- Sidebar mit Status, Abo-Karten und Watchdog
- Toggle zwischen Gratis- und Experten-Modus
- Chat-Interface (Platzhalter – API-Anbindung folgt)

## GitHub Pages aktivieren

1. Repo-Settings → Pages
2. Source: Deploy from a branch → Branch `main` / `/ (root)`
3. Save – nach ein paar Minuten ist die Seite unter der URL oben erreichbar.
